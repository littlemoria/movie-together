## 三、隐私保护指引（后台表单逐项填写）

**收集的用户信息类型**
```
邮箱地址
```

**收集场景**
```
用户在登录页主动输入账号与密码时收集邮箱地址
```

**用途**
```
用于账号登录与身份验证，识别操作用户是否为账号本人
```

**存储方式**
```
存储于开发者自有云数据库（Supabase），数据位于境内节点
```

**保存期限**
```
自账号创建起至账号注销为止
```

**第三方共享**
```
不与任何第三方共享
```

**收集方式**
```
用户主动输入（非自动采集、非被动记录）
```

**勾选项**：在「用户隐私保护指引」表单中勾选 **邮箱地址**，并设为必填。

## 四、小程序内隐私政策展示文案

放在「设置」页底部，文案需覆盖后台声明的每一项：

```
隐私保护指引

一、我们收集的信息
我们仅收集您主动输入的邮箱地址，用于账号登录与身份验证。
我们不收集您的手机号、位置、相册、摄像头、麦克风等任何其他信息。

二、信息的使用
邮箱地址仅用于识别账号本人，不用于其他用途，不与任何第三方共享。

三、信息的存储
您的信息存储于开发者自有的云数据库中，位于境内节点。
在账号存续期间保存，账号注销后删除。

四、您的权利
您可以随时通过设置页的「退出登录」清除本地登录状态，
也可以联系开发者申请删除账号及其关联数据。

五、联系我们
如有隐私相关疑问，请通过微信联系开发者。
```
